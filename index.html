05

Apna Apna – Trip Expense Splitting ApplicationLive application · Live

Live site ↗ (apnaapna.online, opens in a new tab)

Overview

A mobile-first PWA for recording and organizing group trip expenses, with trip and member management, expense categories, per-trip currency selection, and editing or deleting of entries.

  • React
  • Vite
  • Tailwind CSS
  • PWA
  • localStorage
  • Vitest
  • Vercel

Highlights

  • Implemented expense-splitting logic in integer minor units: each expense has its own payer and participants, shares always add up to the exact amount, and balances are amount paid minus share owed.
  • Added a settlement view showing who owes whom, JSON and CSV export, and Vitest unit tests for the calculation, settlement, and storage logic.
